# Продолжение разработки CybOS-demo

## Рабочая основа

Рабочий стол развивается в этом репозитории. Доменная логика остаётся в существующих соседних библиотеках; версия каждого компонента закреплена в components.lock.json. Общий каталог находится в cybOS/ecosystem.json.

После клонирования:

```bash
python3 scripts/bootstrap_components.py
python3 scripts/bootstrap_components.py --verify
python3 -m unittest discover -s scripts/tests -v
cargo test --locked -j 4
cargo run --locked -j 4
```

Bootstrap проверяет весь список до загрузки. Существующий checkout с другим HEAD отклоняется, локальная работа сохраняется. Изменённые файлы при совпадающем HEAD разрешены для разработки; `--verify` не подтверждает чистоту дерева. Недостающий checkout сначала загружается во временную папку и появляется на месте только после успешной проверки. Повторный запуск после сетевой ошибки безопасен.

macOS-лаунчер восстанавливает компоненты, учитывает изменения исходников соседних библиотек и берёт версию из Cargo.toml. Сборка и упаковка используют --locked.

## Следующий сквозной сценарий

Сначала довести безопасность локального чата: два узла → подтверждение идентичности → сообщение → сохранение → ACK → повторный запуск. Критерии: чужой/сменившийся ключ отклонён; ошибка сохранения не даёт успешный ACK; занятый порт виден в UI; лимит сессий и deadline проверены. После этого — знания и задача агента с сохраняемым результатом.

Реальный двухустройственный тест обязателен перед выводом о готовности LAN/BLE. Проверка сборки и loopback не доказывает совместимость двух Mac.

- cybOS — 23 теста после обновления каталога.
- Robotcyb-game / RobotCYB-Price-Tracker / cicadafarm / cicadafarm-game / Egolution / robotcyb — 104 теста суммарно.
