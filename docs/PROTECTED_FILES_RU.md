# Защищённые файлы CybOS

В CybWallet доступен раздел «Защищённые файлы». Он хранит содержимое и имена небольших документов внутри основной SQLCipher-базы, под ключом профиля. Дополнительный пароль или новый формат криптографии не вводится.

1. Войдите в CybOS и откройте CybWallet.
2. Введите путь исходного файла и нажмите «Сохранить защищённую копию».
3. Выберите сохранённый файл из списка.
4. Для экспорта укажите полный путь нового файла и нажмите «Выгрузить выбранный файл».

Исходник сохраняется без изменений и остаётся незашифрованным. Экспорт тоже создаёт незашифрованную копию. Существующий файл назначения не заменяется. Для публикации экспортированной копии требуется поддержка hard link в файловой системе. Файл на Unix создаётся с правами 0600; Windows ACL пока отдельно не настраиваются.

Ограничения первого этапа: 32 МиБ на файл, 256 МиБ суммарного содержимого и 1024 записи. Импорт читает максимум 32 МиБ + 1 байт и проверяет квоту в транзакции. Выполнение идёт в отдельном потоке. Операция, начатая до блокировки интерфейса, продолжится в фоне. Данные операции доступны в памяти процесса; это не изоляция от ОС.

Автоматический перенос старых вложений, отправка файлов в CybChat, удаление защищённых копий и зашифрованное хранение торрент-загрузок ещё не подключены. Большие фильмы и раздачи CybLex остаются в текущем файловом хранилище. Для резервного копирования сохраняйте всю папку данных при закрытом приложении, включая зашифрованную базу и profile-vault.json, а 24 слова храните отдельно.

Проверка на macOS ARM64 включает импорт и экспорт с совпадением байтов, сохранение исходника, отказ при существующем назначении, неизвестном ID, превышении размера и неверном ключе. Контрольный текст отсутствует в байтах зашифрованной базы. Ручной интерфейс и другие платформы в этом этапе не проверены.
