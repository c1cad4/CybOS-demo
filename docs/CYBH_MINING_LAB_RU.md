# CybHero CPU lab в CybOS

Открыть: **Токены → CybHero · CPU lab**. Панель управляет уже запущенным отдельным лабораторным узлом через RPC; она не устанавливает и не запускает daemon, не создаёт кошелёк.

1. Собрать лабораторный CybHero по инструкции его репозитория. Запустить узел в offline fakechain с RPC только на 127.0.0.1; порт по умолчанию 28981.
2. Нажать «Проверить соединение». CybOS проверяет тип сети, offline-режим и точный лабораторный genesis.
3. Ввести публичный адрес тестового кошелька. Seed и приватные ключи вводить не нужно. Контрольная сумма и принадлежность адреса сети окончательно проверяются узлом.
4. Выбрать число CPU-потоков (не больше четырёх и доступных процессоров), подтвердить согласие на нагрузку, затем запустить.
5. Остановить кнопкой и проверить подтверждённое неактивное состояние. **Закрытие CybOS не останавливает отдельный узел.**

Перед каждой командой запуска или остановки проверка сети повторяется. Подключение ограничено числовым loopback-адресом, прокси и HTTP-перенаправления отключены. RPC ограничен таймаутом и размером ответа. Ошибка очищает старые измерения; снимок состояния содержит возраст. Показатели обновляются по запросу, без обещаний постоянного мониторинга.

## Границы реализации

Это лабораторное управление CPU-майнингом. GPU, кошелёк, выплаты, баланс CYBH и промышленная сеть в панель не подключены. Идентификация genesis предотвращает случайное подключение к другой цепочке, но не аутентифицирует локальный процесс против вредоносного ПО на компьютере.

Контролы и предупреждение о закрытии переведены в существующем каталоге языков. Часть пояснений и ошибок бэкенда остаётся на русском.

## Проверка

Локальная ARM64 debug-сборка проходит. Полный набор Rust: 95 тестов успешно, 3 пропущены. Шесть тестов RPC используют имитированный HTTP-сервер: проверяют параметры запуска, остановку, отказ на чужой сети и отсутствие неявного запуска. Проверка всех переводов также проходит. Реальный майнинг на пользовательском Mac в этой проверке не запускался. Тестовое приложение запущено с отдельной базой; переключение вкладки CPU lab через UI-автоматизацию не подтверждено.


## Импорт журнала

В раскрывающемся разделе «Журнал тестовых наград» указать путь к JSON, экспортированному `tools/reward_report.py` из CybHero. Снимок содержит дату, высоту, статусы блоков и распределения в атомарных единицах. Это исторические данные лаборатории; CybOS не считает их текущим балансом, не проверяет подпись отчёта и не отправляет выплаты. При смене пути или ошибке чтения старый снимок удаляется с экрана. Размер ограничен 4 MiB, схема и genesis проверяются. Новые пояснения журнала пока на русском.

Обновлённая проверка: 97 Rust-тестов прошли, 3 пропущены; ARM64 debug-сборка успешна. В CybHero 63 Python-теста прошли. Реальная лабораторная нативная сборка последней ревизии CybHero успешно прошла в GitHub Actions (run 38192203814), но локальный нативный узел на Mac ещё не собран и не подключён.


## Реальное подключение на macOS

Daemon и wallet RPC собраны локально для ARM64. На отдельной offline-сессии выполнен тест `real_lab_readonly_connection` с явным `CYBH_LAB_TEST_PORT=28981`: genesis проверен штатным клиентом, высота 1, mining_active=false. Узел завершён через Ctrl+C, закрытие порта подтверждено. Майнинг не запускался. Тест по умолчанию ignored, так как требует отдельно запущенного узла; запуск: `CYBH_LAB_TEST_PORT=28981 cargo test real_lab_readonly_connection -- --ignored --nocapture`. Это проверка RPC-клиента, не визуальная проверка кнопок приложения.


## Проверка кнопок на Mac

На исходной отдельной сборке CybOS-Mining-Test проверены соединение, ввод публичного временного адреса, согласие на CPU, запуск и остановка. Измерено: CPU 1, 203 H/s, высота 5 после остановки. Статус «Тестовый майнер остановлен» подтверждён через интерфейс. Затем node/wallet завершены, оба RPC-порта закрыты. GUI журнала в этой проверке не тестировался. Отдельный native mining smoke: высота 1→4, 216 H/s, принятый блок и stop подтверждены; реальных CYBH и транзакций нет.
