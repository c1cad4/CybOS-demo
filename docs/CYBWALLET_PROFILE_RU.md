# CybWallet: ключ профиля и первый вход

При первом запуске пользователь создаёт 24 английских слова BIP39 из 256 бит системной случайности. Фраза восстанавливает локальный ключ профиля CybOS, а не кошелёк Monero/CybHero. На экране нужно подтвердить сохранение и ввести слова №3, №12, №21. Затем задать пароль от 12 символов. При следующих запусках достаточно пароля; восстановление по 24 словам позволяет задать новый пароль. На новом устройстве можно импортировать эту же фразу. Чаты и файлы она сама не восстанавливает — нужна отдельная копия данных.

В eframe сначала создаётся только Gate. CybOs::default и его службы создаются после успешного создания/открытия vault. Файл отсутствует — онбординг; неверный пароль — отказ; повреждённый формат — блокировка без сброса. После входа доступна вкладка CybWallet с идентификатором профиля. Выход из приложения снова закрывает UI при следующем запуске; автоматическая блокировка и Touch ID ещё не реализованы. Отдельно запущенные daemon/VPN не завершаются этим ключевым хранилищем.

## Защита ключа

В profile-vault.json сохраняется только зашифрованная 32-байтовая entropy и служебные метаданные. Argon2id v19: 64 MiB, 3 прохода, 1 lane, выход 32 байта; случайная соль 16 байт. XChaCha20-Poly1305: случайный nonce 24 байта; AAD привязывает назначение/версию и ID. Пароли, entropy и строки фразы обёрнуты в Zeroizing, а bip39/argon2 используют zeroize. Это не гарантия отсутствия копий в памяти GUI/ОС. Фраза не записывается в SQLite, логи или telemetry этим модулем, и не копируется в буфер обмена автоматически.

Файл создаётся с Unix mode 0600 через private temp, fsync и публикацию без перезаписи; восстановление публикует новый зашифрованный файл атомарной заменой после проверки фразы. Existing файл не перезаписывается при обычном создании. Directory fsync, Windows ACL, межпроцессный lock и безопасное стирание SSD не реализованы. Шифруется ключ профиля; прежняя SQLite-база, чаты, остальные служебные ключи и файлы пока не переведены в encrypted storage. Это локальная граница UI, не защита от хозяина ОС или вредоносного кода.

## Форматы и границы

BIP39 описывает 24 слова для 256 бит entropy: https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki

Legacy Monero использует 25 слов, включая checksum: https://docs.getmonero.org/mnemonics/legacy/

Не используется самодельное преобразование BIP39 в spend key CybHero. Кошелёк реальных средств, blockchain-адреса, подпись и отправка транзакций пока не подключены. UI ключевого профиля сейчас на русском, BIP39 wordlist на английском. Для средств нужен отдельный проверенный chain-specific wallet и аудит.

## Проверка

ARM64 debug-сборка успешна; 102 Rust-теста прошли, 4 ignored. Три vault-теста используют публичный zero-entropy BIP39-вектор: password/tamper refusal, совпадение recovery ID и точность 24 слов, запись/восстановление/отказ от перезаписи, сохранение файла при ошибке и Unix permissions. В тестовой сборке появилась вкладка CybWallet после открытия профиля. Agent не создавал личную фразу/пароль пользователя и не читал их. Полный автоматический UI-сценарий onboarding не выполнялся.
