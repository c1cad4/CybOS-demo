# cybOS - Cyberpunk Operating System Interface

A futuristic cyberpunk control panel with neon green aesthetics, built with p5.js.

## Features

- **Neon Green Cyberpunk Theme**: Complete visual overhaul with cyberpunk aesthetics
- **Interactive Pussy Search System**: Real-time target tracking with neon green scanning
- **CybCore**: Animated energy core with throttle control
- **3D Hologram Display**: Rotatable ship schematic
- **Signal Grid**: Animated data flow visualization
- **CybChat**: Real-time cyberpunk chat with bots and users including master, boot, robotcyb, and other cyberpunk characters
- **Cyber Knowledge Graph**: Dynamic neural network that constantly grows with new neurons and connections
- **Terminal Interface**: Command-line interface with cyberpunk commands
- **Alert System**: Dynamic alert levels with visual effects

## Controls

- **W** — Toggle WARP
- **S** — Toggle SPHERE  
- **A** — Toggle ORACLE
- **D** — Toggle SENATE
- **Space** — Send a PUSSY SEARCH ping
- **T** — Focus command terminal
- **ESC** — Exit terminal mode
- **Mouse**:
  - Click anywhere: spawn energy ripple
  - Drag on the core ring: adjust THROTTLE
  - Drag on hologram: rotate projection
  - Hover over toggles/buttons for info

## Terminal Commands

- `help` - Show available commands
- `scan` - Perform sensor sweep
- `status` - Display ship systems status
- `warp [on/off]` - Control warp drive
- `sphere [on/off]` - Control sphere systems
- `oracle [on/off]` - Control navigation
- `senate [on/off]` - Control senate systems
- `set course [id]` - Set navigation target
- `divert power [system]` - Reallocate power
- `full report` - Show all ship systems
- `clear` - Clear terminal
