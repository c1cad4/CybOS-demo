# CYBCORE Ecosystem

A modular, local-first ecosystem for people, AI agents, robots and projects benefiting living systems.

## Proposed independent repositories

| Repository | Scope |
| --- | --- |
| cybOS | Desktop UI, local-first client, permissions and user experience |
| CybCore | Service runtime, API, node identities and orchestration |
| CybChain | Deterministic ledger and experimental consensus devnet |
| CybMind | Multi-agent research coordination and bounded learning |
| CybBrain | Provenance-aware knowledge and personal memory |
| CybGrowth | Voluntary learning goals and verified contribution portfolios |
| CybTrust | Domain-specific evidence, attestations and appeals |
| CybShield | Capabilities, policy enforcement and safety gates |
| CybLex | Opt-in encrypted content distribution and storage |
| CybRobot | Safe robot adapters, simulation and human-authorized execution |

These are **proposed repository names**, not existing repositories. Until separate repositories are provisioned, development is staged in the existing CybOS-demo repository.

## Principles

1. Human dignity is not scored; progress profiles are optional and private by default.
2. Models may research and propose changes, but cannot expand their own permissions.
3. Robot control is independently safety-gated and locally interruptible.
4. Learning claims require reproducible evidence; memory is not model training.
5. The blockchain records minimal attestations, not sensitive personal data.
6. No deployed token, ASI or post-quantum security is claimed without verification.

## First vertical slice

Two sandboxed research agents exchange signed, bounded tasks, produce evidence and request independent evaluation. cybOS displays tasks, a private learning journal and opt-in contribution attestations. No wallet, robot actuator or public blockchain permissions in the first slice.
